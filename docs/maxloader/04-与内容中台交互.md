# 04 · 与内容中台交互：axios 封装 + 剧集注册 + 七牛上传

> 上传一部剧不是"把文件丢给七牛"这么简单，而是一条链路：**先在 CMS 注册剧集 → 申请七牛上传 token → 传到七牛 → 七牛回调 CMS 触发转码同步**。本篇讲客户端这侧怎么封装 axios、怎么约定业务错误、以及注册-上传-回调是怎么串起来的。

## 一、统一的 axios 实例

所有调 CMS 的请求都走一个封装好的实例（`src/main/http/request.ts`），集中处理 baseURL、超时、鉴权头、日志：

```ts
import axios, { type AxiosInstance } from 'axios'
import { config } from '../config'

let token: string | null = null
export function setToken(t: string | null) { token = t }
export function getToken() { return token }

export const http: AxiosInstance = axios.create({
  baseURL: config.apiBase,   // test/prod 由构建环境决定（见第一篇）
  timeout: 30000,
})

// 请求拦截：自动加 Bearer token + 记录耗时起点 + 打日志
http.interceptors.request.use((cfg) => {
  if (token) cfg.headers.Authorization = `Bearer ${token}`
  ;(cfg as any).__t = Date.now()
  console.log(`[HTTP →] ${cfg.method?.toUpperCase()} ${cfg.baseURL}${cfg.url}`)
  return cfg
})
```

响应拦截做两件事：打日志、以及**统一捕获接口错误上报**（这部分见第五篇的错误上报）：

```ts
http.interceptors.response.use(
  (res) => {
    const ms = Date.now() - (res.config as any).__t
    console.log(`[HTTP ←] ${res.status} ${res.config.url} (${ms}ms)`)
    // 业务错误：HTTP 200 但 data.code !== 200，统一上报
    const data: any = res.data
    if (data && data.code && data.code !== 200) {
      void reportError('api', `${res.config.method?.toUpperCase()} ${res.config.url} → code=${data.code} ${data.msg || ''}`)
    }
    return res
  },
  (err) => {
    // 网络错误 / 非 2xx（ECONNRESET、超时、5xx 等）统一上报
    const cfg = err.config ?? {}
    const status = err.response?.status ?? err.code ?? 'ERR'
    void reportError('api', `${(cfg.method||'').toUpperCase()} ${cfg.url} → ${status}`, err.stack)
    return Promise.reject(err)
  },
)
```

## 二、业务错误约定：HTTP 200 但 code ≠ 200

这套后端（和很多国内后端一样）用 **HTTP 200 + body 里的 `code` 字段**表达业务结果，不是用 HTTP 状态码。所以每个接口封装都统一判 `code`：

```ts
// src/main/http/shortmax.ts
export async function sendSmsCode(phoneNumber: string): Promise<void> {
  const { data } = await http.post('/sendSmsCode', { phoneNumber })
  if (data.code !== 200) throw new Error(data.msg || '短信发送失败')
}

export async function getQiNiuTokenList(keys: string[]): Promise<string[]> {
  const { data } = await http.post('/common/getQiNiuToken', { keys })
  if (data.code !== 200) throw new Error('获取七牛上传 Token 失败')
  return data.data
}
```

这个约定很重要，它决定了上一篇 `classifyError` 里对错误的判断——网络层错误走 `err.response.status`，业务层错误走抛出的 `Error(msg)`。

## 三、短剧搜索：服务端分页

搜索用 CMS 的分页接口，客户端做**关键词路由**：纯数字当短剧编码（精确），否则按剧名模糊搜：

```ts
export async function searchShortplay(keyword, pageNum = 1, pageSize = 20) {
  const kw = (keyword || '').trim()
  const params: Record<string, unknown> = { pageNum, pageSize }
  if (kw) {
    if (/^\d+$/.test(kw)) params.shortPlayCode = kw       // 编码：精确/in 查询
    else params.shortPlayNameExt = kw                      // 剧名：模糊（名称/别名/来源名/简称）
  }
  const { data } = await http.get('/drama/shortplay/list', { params })
  if (data.code !== 200) throw new Error(data.msg || '短剧搜索失败')
  const rows = (data.rows ?? []).map((r: any) => ({
    id: r.id,
    shortPlayCode: r.shortPlayCode,
    shortPlayName: r.shortPlayName,
    coverUrl: resolveCoverUrl(r.coverId ?? r.horizontalCoverId),  // ★ 封面是相对路径
    createSource: r.createSource,   // 0=旧流程 1=自制剧（决定已存在集能否重传）
  }))
  return { rows, total: Number(data.total ?? rows.length) }
}
```

> 一个真实踩过的坑：接口返回的封面 `coverId` 是**相对路径** `/images/cover/xxx.png`，直接塞 `<img src>` 显示不出来（那个路径在 CMS 上需要鉴权）。得拼上静态资源 CDN 域名：
> ```ts
> const ASSET_CDN = 'https://akamai-static.shorttv.live'
> function resolveCoverUrl(path?: string) {
>   if (!path) return undefined
>   if (/^https?:\/\//i.test(path)) return path  // 已是完整 URL 直接用
>   return ASSET_CDN + (path.startsWith('/') ? path : '/' + path)
> }
> ```

## 四、上传前必须先"注册剧集"

七牛只负责存文件，CMS 才知道"这个文件是哪部剧的第几集"。所以**上传前必须先调 CMS 注册**，注册成功任务才入队：

```ts
// src/main/scheduler/queue.ts
async function registerDramaBatch(shortPlay, files, mode) {
  const prepared = files.map((f) => ({ ...f, fileUUID: uuidv4() }))  // 每个文件分配 UUID
  const items: DramaUploadItem[] = prepared.map((p) => ({
    md5: '',
    ttFileKey: p.fileUUID,
    fileUUID: p.fileUUID,
    fileName: p.fileName,                    // CMS 据此解析集数
    shortPlayCode: shortPlay.shortPlayCode,
    shortPlayName: shortPlay.shortPlayName,
    transedPlatform: 1,                      // 1=七牛，后端据此走七牛回调链路
  }))
  if (mode === 'update') await batchUpdateDramaUpload(items)  // 修改重传
  else await batchAddDramaUpload(items)                       // 新增
  return prepared
}
```

`fileUUID` 是串起整条链路的钥匙：**注册时用它、七牛存储 key 用它（`hls/{fileUUID}.{ext}`）、上传成功埋点也用它**。三处对齐，CMS 才能把七牛回调的文件对应回剧集。

新增 vs 修改重传走不同接口，后端对"审核通过的集能否覆盖"有不同校验：

```ts
export async function batchAddDramaUpload(items: DramaUploadItem[]): Promise<void> {
  const { data } = await http.post('/drama/drama/batchAddDramaUpload', items)
  if (data.code !== 200) throw new Error(data.msg || '注册剧集失败')
}
export async function batchUpdateDramaUpload(items: DramaUploadItem[]): Promise<void> {
  const { data } = await http.post('/drama/drama/batchUpdateDramaUpload', items)
  // 后端会拒绝"审核通过"的集的修改，msg 形如"请使用批量导入功能新增..."，直接抛出交上层提示
  if (data.code !== 200) throw new Error(data.msg || '修改剧集失败')
}
```

## 五、完整链路：注册 → 申请 token → 上传 → 回调

把这几步串起来看整条上传链路：

```
1. registerDramaBatch     客户端 → CMS：注册剧集（fileUUID / fileName / shortPlayCode）
2. getQiNiuTokenList      客户端 → CMS：按 storeKey=hls/{fileUUID}.ext 申请上传 token
                          （token 内置 callbackUrl，指向 CMS 的七牛回调接口）
3. uploadToQiniu          客户端 → 七牛：分片上传文件到 storeKey
4. 七牛回调 CMS            七牛 → CMS：上传完成后带着 callbackUrl 回调
                          CMS 收到回调 → 触发转码（微帧）+ 同步 S3 + 状态流转
5. ttUploadJsSuccessLog   客户端 → CMS：上传成功埋点（传裸 fileUUID）
```

关键在第 2 步：**七牛上传 token 是按具体 storeKey 签发的，且内置了 callbackUrl**。所以文件传到七牛后，七牛会主动回调 CMS——客户端不需要自己再通知 CMS "传完了"，转码和后续流转都由回调触发。客户端第 5 步的埋点只是统计用。

申请 token 和上传在 `runOne` 里（见上一篇）：

```ts
const storeKey = `hls/${task.fileUUID}.${ext}`
const [token] = await getQiNiuTokenList([storeKey])   // 按 key 申请
await uploadToQiniu(task.filePath, token, storeKey, onProgress, checkpointPath(task.id), source)
await ttUploadJsSuccessLog(task.fileUUID!)            // 埋点
```

## 六、拖拽导入怎么拿到真实文件路径

上传要的是本地文件的**绝对路径**（给七牛 SDK `putFile`）。渲染层拖进来的是浏览器 `File` 对象，新版 Electron 里 `File.path` 已废弃，正路是 preload 里用 `webUtils`：

```ts
// preload
files: {
  fromDropped: (fileList: File[]) => {
    const paths = fileList.map((f) => webUtils.getPathForFile(f))  // ★ 拿真实磁盘路径
    return ipcRenderer.invoke('dialog:stat-files', paths)          // 主进程补 size 等信息
  },
  pickVideos: () => ipcRenderer.invoke('dialog:pick-videos'),      // 原生文件选择框
  pickVideoFolder: () => ipcRenderer.invoke('dialog:pick-video-folder'),  // 递归导入文件夹
}
```

主进程侧 `dialog:pick-video-folder` 会递归遍历文件夹、过滤出视频文件，一次导入整部剧。

## 小结

- 一个 axios 实例集中管 baseURL / 超时 / Bearer / 日志 / 错误上报。
- 业务错误约定：HTTP 200 看 `data.code`，非 200 抛 `msg`。
- 上传前必须先注册剧集；`fileUUID` 串起注册、存储 key、埋点三处。
- token 按 storeKey 签发且内置 callbackUrl，七牛传完主动回调 CMS 触发转码，客户端不用自己通知。
- 拖拽文件用 `webUtils.getPathForFile` 拿真实路径。
