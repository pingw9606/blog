# MaxLoader Electron 实战系列 · 总览

> 用 Electron + Vue3 从零做一个**能扛住关软件、断网、失败重试**的短剧批量上传桌面工具。这个系列不是概念科普，而是把项目里**真实跑在生产的代码**一段段拆开讲：三进程怎么分工、IPC 怎么安全暴露、上传队列的断点续传/自动重试/并发怎么实现、怎么和内容中台交互、怎么打包发版。读完能照着搭一个自己的。

## 这是什么项目

内容运营要把短剧视频批量传到内容中台（CMS）。网页上传关页面就断、要一直盯着、失败看不懂。MaxLoader 把这件事做成桌面工具：

- 搜索短剧 → 拖入整个文件夹 → 后台队列批量上传
- **关软件、断网都不丢进度**（断点续传 + 启动恢复）
- 失败**自动重试**、看得懂原因、能手动重试
- 可设并发数、支持暂停/继续、修改重传

技术栈：**Electron**（主进程 Node + 渲染层 Vue3 + Element Plus）+ **vite-plugin-electron** 打包 + **electron-builder** 出安装包 + 七牛云上传 + 一套自建轻服务做更新/统计/公告。

## 贯穿全系列的一条设计红线

> **所有"锦上添花"的能力（更新检查、统计、公告、上报）都必须失败静默、短超时、绝不阻断上传主流程。** 后端挂了、网络断了，用户照样能传剧。这条约束会在很多代码里以 `try/catch 返回 null`、`timeout: 5000`、旁路 `void fn()` 的形式反复出现。
